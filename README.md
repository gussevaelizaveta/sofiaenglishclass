# Hello Again! — My English

Интерактивный урок английского языка. Сайт работает как статический HTML-файл и не требует сборки или серверных зависимостей.

## GitHub Pages
1. Загрузите содержимое архива в корень репозитория (не сам ZIP).
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
4. Откройте адрес Pages, который покажет GitHub.

`index.html` находится в корне архива.
